# Original CFGNN Results (Reproduced)

## Environment
- Platform: Kaggle
- GPU: Tesla T4
- Framework: PyTorch

## Dataset
Reduced dataset derived from the original dataset
due to hardware limitations.

## Test Results

| Metric    | Value |
|-----------|--------|
| Accuracy  | 0.8346 |
| Precision | 0.3677 |
| Recall    | 0.2658 |
| F1-score  | 0.3085 |

## Notes
These results represent the performance of the original CFGNN model
when trained on the reduced dataset used in this study.

They serve as a reference baseline for evaluating
the improved CFGNN variants proposed in this project.
